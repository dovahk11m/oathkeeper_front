# GroupController API 명세서

`GroupController`에 구현된 그룹 및 관련 기능(채팅, 멤버 관리)에 대한 API 명세입니다.

---

## **1. 공통 정보 (General Information)**

### **1.1. 인증 (Authentication)**

- 본 명세서의 모든 API는 인증이 필요합니다.
- API 요청 시, HTTP 헤더에 로그인 시 발급받은 JWT를 반드시 포함해야 합니다.
- **헤더 형식**: `Authorization: Bearer <your_jwt_token>`

### **1.2. 표준 응답 형식 (`CommonResponse<T>`)**

- 모든 API의 성공 응답은 아래와 같은 `CommonResponse` 형식으로 감싸여 반환됩니다.

```json
{
  "success": true,
  "data": { ... }, // API별 실제 데이터
  "message": "요청에 성공했습니다."
}
```

### **1.3. 페이징 응답 형식 (`PageResponseDTO<T>`)**

- 페이징이 적용된 API의 `data` 필드는 아래와 같은 `PageResponseDTO` 구조를 가집니다.

```json
{
  "content": [ ... ], // 실제 데이터 DTO 배열
  "page": 0, // 현재 페이지 번호 (0부터 시작)
  "size": 20, // 페이지 당 데이터 수
  "totalPage": 5, // 전체 페이지 수
  "totalElements": 98, // 전체 데이터 수
  "last": false, // 마지막 페이지 여부
  "navigation": { // 페이지네이션 UI를 위한 정보
    "currentPage": 0,
    "displayRange": 5,
    "startPage": 0,
    "endPage": 4,
    "hasPrev": false,
    "hasNext": true,
    "pageNumbers": [0, 1, 2, 3, 4]
  }
}
```

## **2. 그룹 API (Group APIs)**

### **2.1. 그룹 생성**

- **Method**: `POST`
- **URL**: `/api/groups`
- **Request Body**:
    ```json
    {
      "groupName": "새로운 스터디 그룹"
    }
    ```
- **Success Response (201 Created)**:
    - `data` 필드에는 생성된 그룹의 `ID`가 포함됩니다.
    ```json
    {
      "success": true,
      "data": 10, // 생성된 그룹의 ID
      "message": "그룹이 생성되었습니다."
    }
    ```

### **2.2. 내 그룹 목록 조회 (페이징)**

- **Method**: `GET`
- **URL**: `/api/groups?page=0&size=20`
- **Query Parameters**:
    - `page`: 조회할 페이지 번호 (0부터 시작, 기본값: 0)
    - `size`: 페이지 당 그룹 수 (기본값: 20)
- **Success Response (200 OK)**:
    - `data` 필드는 `PageResponseDTO<GroupListResponse>` 형식입니다.
    - `content` 배열의 각 요소는 `GroupListResponse` 객체입니다. (해당 DTO의 정확한 필드는 서버 코드 확인 필요)

### **2.3. 그룹 탈퇴**

- **Method**: `DELETE`
- **URL**: `/api/groups/{groupId}/leave`
- **Path Variable**: `groupId` (탈퇴할 그룹의 ID)
- **Success Response (200 OK)**:
    ```json
    {
      "success": true,
      "data": null,
      "message": "그룹에서 탈퇴했습니다."
    }
    ```

## **3. 그룹 멤버 API (Group Member APIs)**

### **3.1. 그룹에 멤버 추가**

- **Method**: `POST`
- **URL**: `/api/groups/{groupId}/members`
- **Path Variable**: `groupId` (멤버를 추가할 그룹의 ID)
- **Request Body**:
    ```json
    {
      "memberEmails": ["user2@test.com", "user3@test.com"]
    }
    ```
- **Success Response (200 OK)**:
    ```json
    {
      "success": true,
      "data": null,
      "message": "멤버가 그룹에 추가되었습니다."
    }
    ```

### **3.2. 그룹 멤버 목록 조회 (페이징)**

- **Method**: `GET`
- **URL**: `/api/groups/{groupId}/members?page=0&size=20`
- **Path Variable**: `groupId` (조회할 그룹의 ID)
- **Query Parameters**:
    - `page`: 페이지 번호 (기본값: 0)
    - `size`: 페이지 당 멤버 수 (기본값: 20)
- **Success Response (200 OK)**:
    - `data` 필드는 `PageResponseDTO<GroupMemberResponse>` 형식입니다.
    - `content` 배열의 각 요소는 `GroupMemberResponse` 객체입니다. (해당 DTO의 정확한 필드는 서버 코드 확인 필요)

## **4. 그룹 채팅 API (Group Chat API)**

### **4.1. 이전 대화 내용 조회 (페이징)**

- **Method**: `GET`
- **URL**: `/api/groups/{groupId}/chat/messages?page=0&size=30&sort=sentAt,desc`
- **Path Variable**: `groupId` (조회할 그룹의 ID)
- **Query Parameters**:
    - `page`: 페이지 번호 (기본값: 0)
    - `size`: 페이지 당 메시지 수 (기본값: 30)
    - `sort`: 정렬 기준 (기본값: `sentAt,desc` - 보낸 시간 기준 내림차순)
- **Success Response (200 OK)**:
    - `data` 필드는 `PageResponseDTO<ChatResponse>` 형식입니다.
    - `content` 배열의 각 요소는 `ChatResponse` 객체입니다. (해당 DTO의 정확한 필드는 서버 코드 확인 필요)

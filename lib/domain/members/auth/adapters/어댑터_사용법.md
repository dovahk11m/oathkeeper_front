# 소셜 로그인 어댑터 패턴 사용법

이 문서는 우리 프로젝트의 소셜 로그인 기능이 어떻게 **어댑터 패턴(Adapter Pattern)**을 통해 구현되었는지 설명합니다.

---

## 1. 왜 어댑터 패턴을 사용하는가?

> "여러 나라의 콘센트 모양이 달라도, 여행용 멀티 어댑터 하나만 있으면 모든 기기를 충전할 수 있습니다."

카카오, 페이스북, 구글 등 각 소셜 로그인 SDK는 모두 자신만의 초기화 방법과 로그인 API를 가지고 있습니다. 만약 이를 `if/else`나 `switch`로 분기 처리한다면, `AuthProvider`나 특정 서비스 파일이 모든 SDK의 구현 방식을 알아야 하므로 코드가 복잡해지고 확장성이 떨어집니다.

어댑터 패턴은 이 문제를 우아하게 해결합니다.

- **목표**: `AuthProvider`가 "카카오 방식", "페이스북 방식"을 전혀 몰라도 되도록, 모든 소셜 로그인을 **하나의 통일된 방식으로 호출**하게 만든다.
- **해결책**: 각기 다른 SDK의 "콘센트" 모양을 우리가 정의한 표준 "플러그" 모양으로 변환해주는 **어댑터**를 만듭니다.

## 2. 핵심 구성 요소

- **`SocialLoginAdapter` (추상 클래스)**
  - 우리가 정의한 표준 **"플러그"**입니다.
  - `Future<String> login()` 이라는 단 하나의 메소드만 정의되어 있습니다.
  - 이 `login()` 메소드는 어떤 소셜 로그인이든, 성공 시 서버에 전달해야 할 **인증 코드(Authorization Code 또는 Access Token)**를 문자열로 반환할 것을 약속합니다.

- **`KakaoLoginAdapter`, `FacebookLoginAdapter` (구현 클래스)**
  - 각 나라의 "콘센트" 모양에 맞는 **"어댑터"**입니다.
  - `SocialLoginAdapter`의 `login()` 메소드를 각자의 방식대로 구현합니다.
  - `KakaoLoginAdapter`는 내부적으로 카카오 SDK를 호출하고, `FacebookLoginAdapter`는 페이스북 SDK를 호출합니다. 이 복잡한 과정은 각 어댑터 파일 안에 완벽하게 캡슐화됩니다.

## 3. 사용 방법 (`AuthProvider`에서의 활용)

`AuthProvider`는 이제 어떤 소셜 로그인 방식인지 신경 쓸 필요 없이, 필요한 어댑터를 생성하고 `login()` 메소드를 호출하기만 하면 됩니다.

```dart
// lib/domain/members/auth/auth_provider.dart

/// [카카오 로그인] - UI에서 호출
Future<void> signInWithKakao() async {
  state = state.copyWith(isLoading: true, error: null);
  try {
    // 1. 카카오에 맞는 "어댑터"를 생성한다.
    final adapter = KakaoLoginAdapter();
    // 2. 표준 "플러그"(login() 메소드)를 호출한다.
    final authCode = await adapter.login();
    // 3. 반환된 인증 코드로 우리 서버에 로그인한다.
    await login(KakaoLoginStrategy(code: authCode));
  } catch (e) {
    // ... 에러 처리
  }
}
```

## 4. 새로운 소셜 로그인 추가하기 (예: Google 로그인)

이 구조의 가장 큰 장점은 **새로운 기능 추가가 매우 간단하다**는 점입니다.

1.  **`GoogleLoginAdapter.dart` 파일 생성**: `adapters` 폴더에 새 어댑터 파일을 만듭니다.
2.  **`SocialLoginAdapter` 구현**: `class GoogleLoginAdapter implements SocialLoginAdapter`를 선언하고, `login()` 메소드 내부에 구글 SDK를 사용하여 인증 코드를 받아오는 로직을 구현합니다.
3.  **`AuthProvider`에 메소드 추가**: `signInWithGoogle()` 메소드를 만들고, 그 안에서 `GoogleLoginAdapter`를 사용하도록 위 예시처럼 코드를 작성합니다.

이렇게 하면 기존의 카카오, 페이스북 코드는 전혀 건드리지 않고도 새로운 소셜 로그인 기능을 안전하게 추가할 수 있습니다.

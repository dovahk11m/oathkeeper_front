# 라이브맵 뷰 트리

```
lib/view/live_map/
├── live_map_page.dart              # 메인 - 실시간 지도 페이지
├── live_map_route.dart             # 라우팅 설정
├── test_main.dart                  # [개발/테스트 전용] 단독 실행용 (TODO: 삭제 예정)
└── widgets/
    ├── online_pill.dart            # 접속자 수 표시 위젯
    ├── status_chip.dart            # 상태 칩 위젯
    └── map_control_panel.dart      # 지도 하단 컨트롤 패널
```

## 파일 설명

### 메인 파일

- **live_map_page.dart**: 실시간 지도 기능의 메인 페이지

  - NaverMap 통합
  - WebSocket(STOMP) 연결 및 실시간 위치 업데이트
  - 마커 관리 및 presence 처리
  - 위치 업로드 루프

- **live_map_route.dart**: GoRouter 라우팅 설정

### 위젯 (widgets/)

- **online_pill.dart**: 좌상단 접속자 수 표시
- **status_chip.dart**: 공유 상태, 접속자 수 등을 표시하는 칩
- **map_control_panel.dart**: 하단 컨트롤 패널 (위치 공유 토글, 내 위치로 이동 등)

### 테스트

- **test_main.dart**: LiveMapPage 단독 실행용 테스트 파일
  - 실행: `flutter run -t lib/view/live_map/test_main.dart`
  - 개발 완료 후 삭제 또는 test/ 디렉토리로 이동 필요

## 관련 도메인

- `lib/domain/tracking/`: 위치 추적 관련 DTO, Repository, Provider
  - `tracking_dto.dart`: TrackBatchRequest, TrackPoint (Deprecated: TrackingDto)
  - `live_location_dto.dart`: 실시간 위치 업데이트 DTO
  - `tracking_repository.dart`: 위치 업로드 API
  - `tracking_provider.dart`: 위치 추적 상태 관리

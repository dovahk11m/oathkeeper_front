# Metrics & AI 요약 API 명세

- **작성일:** 2025-11-24
- **작성자:** Oath 서버 개발팀

이 문서는 클라이언트(Flutter) 개발자가 약속(Plan)이 종료된 후, AI가 생성하는 요약 보고서를 조회하는 방법에 대해 안내합니다.

---

## 1. 핵심 API: AI 요약 보고서 조회

AI 요약 보고서는 생성에 시간이 소요되는 **비동기 작업**입니다. 따라서 클라이언트는 아래 API를 **주기적으로 호출(Polling)**하여 최종 결과물을 받아야 합니다.

### `GET /api/plans/{planId}/summary`

- **설명:** 특정 약속(`planId`)에 대한 AI 요약 보고서를 요청합니다.
- **인증:** 필요 (JWT 토큰)

#### 1.1. 응답 시나리오

이 API는 요약 진행 상태(`SummaryStatus`)에 따라 세 가지 다른 응답을 반환합니다.

**1) 요약 생성 시작 또는 진행 중일 때**

- **조건:** 서버가 요약 생성을 막 시작했거나, 아직 처리 중인 경우.
- **HTTP Status:** `200 OK`
- **응답 본문:**
  ```json
  {
    "success": true,
    "data": null,
    "message": "AI 요약 보고서가 생성 중입니다. 잠시 후 다시 시도해주세요."
  }
  ```
- **클라이언트 처리:**
  - 이 응답을 받으면, **2~3초 간격으로 동일한 API를 다시 호출**해야 합니다.
  - 로딩 인디케이터 등을 사용자에게 표시하는 것이 좋습니다.

**2) 요약 생성 완료 시**

- **조건:** AI 요약 보고서 생성이 성공적으로 완료된 경우.
- **HTTP Status:** `200 OK`
- **응답 본문:**
  ```json
  {
    "success": true,
    "data": {
      "id": 2,
      "title": "긴급 트러블슈팅 회의",
      "summary": "약속 #2의 요약입니다. 총 16건의 기록이 있으며..."
    },
    "message": null
  }
  ```
- **클라이언트 처리:**
  - `data.summary`에 포함된 텍스트를 화면에 표시합니다.
  - 이 응답을 받으면 폴링을 중단합니다.

**3) 요약 생성 실패 시**

- **조건:** AI 서버와의 통신 오류 등 예기치 못한 문제로 요약 생성에 실패한 경우.
- **HTTP Status:** `500 Internal Server Error`
- **응답 본문:**
  ```json
  {
    "success": false,
    "data": null,
    "message": "AI 요약 생성에 실패했습니다. 다시 시도해주세요."
  }
  ```
- **클라이언트 처리:**
  - 사용자에게 오류 메시지를 표시하고, "다시 시도" 버튼을 제공하는 것을 권장합니다.
  - 폴링을 중단합니다.

#### 1.2. 전체 흐름 요약 (Polling)

1.  클라이언트는 약속 상세 화면에 진입 시 `GET /api/plans/{planId}/summary`를 **최초 호출**합니다.
2.  만약 응답 메시지가 "생성 중"이라면, 2~3초 대기 후 **다시 호출**합니다.
3.  `data` 필드에 요약 내용이 있거나, 응답이 `500` 에러일 경우 **호출을 중단**합니다.

## 2. 참고: 내부 테스트용 API

> **[주의]** 아래 API들은 서버 개발팀이 로컬 환경에서 테스트 목적으로만 사용하는 API입니다. 클라이언트에서는 **절대 직접 호출하면 안 됩니다.**

- **`POST /api/plans/{planId}/metrics/rollup`**: 수동으로 통계 계산을 트리거합니다.
- **`POST /api/plans/{planId}/metrics/push`**: 계산된 통계를 AI 서버로 수동 전송합니다.
- **`GET /api/plans/{planId}/metrics/summary`**: AI 서버의 원본 JSON 요약을 프록시로 조회합니다. (이름 주입 기능 포함)
- **`POST /api/plans/{planId}/metrics/summary/text`**: LLM 옵션을 포함하여 텍스트 요약을 생성합니다.

이 API들은 실제 서비스 환경에서는 비활성화되어 있습니다.

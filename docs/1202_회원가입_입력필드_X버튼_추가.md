- [x] `StatefulWidget`으로 변경하여 텍스트 입력 상태 추적
- [x] 텍스트가 있을 때만 X 버튼 표시
- [x] X 버튼 클릭 시 텍스트 필드 내용 지우기

- [x] 각 `CustomTextFormField`에 `showClearButton: true` 속성 추가

### 3. 테스트

- [ ] 각 입력 필드에서 X 버튼이 정상적으로 표시되는지 확인
- [ ] X 버튼 클릭 시 내용이 지워지는지 확인

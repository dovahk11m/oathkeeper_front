## 📦 클라이언트에 제공할 API 문서

### 우선순위 1: AI 요약 기능 (필수)

#### 1. `METRIC_API.md` ⭐⭐⭐ **가장 중요**

- **내용:** AI 요약 폴링(Polling) 방식 구현 가이드
- **중요성:** 비동기 AI 요약 처리 방법의 핵심 가이드
- **포함 내용:**
  - 폴링 방식 전체 흐름
  - 3가지 응답 시나리오 (PENDING, COMPLETED, FAILED)
  - Flutter 예시 포함
  - 에러 처리 방법

#### 2. `GROUP_API.md` ⭐⭐⭐

- **내용:** 그룹/채팅 관련 모든 API (AI 요약 포함)
- **주요 엔드포인트:**
  - `GET /api/groups/{groupId}/metrics/summary` - 그룹 AI 요약 조회
  - `GET /api/groups/{groupId}/plans` - 그룹 내 약속 목록
  - `GET /api/groups` - 내 그룹 목록
- **특징:** 인증 필수, 페이징 지원

#### 3. `ERROR(에러응답)API.md` ⭐⭐

- **내용:** 공통 에러 응답 형식
- **중요성:** 모든 API 에러 처리 통일

### 우선순위 2: 실시간 지도 기능

#### 4. `LIVE_MAP_API.md` ⭐⭐⭐

- **내용:** WebSocket 기반 실시간 위치 공유
- **포함 내용:**
  - WebSocket 연결 방법
  - 위치 업데이트 수신
  - 테스트 API 사용법

### 참고용 (필요시 제공)

#### 5. `PLAN_API.md` ⭐

- **내용:** 약속 생성/수정/조회/삭제
- **제공 시점:** 약속 관리 기능 구현 시

#### 6. `MEMBER_API.md` ⭐

- **내용:** 회원 가입/로그인/프로필
- **제공 시점:** 이미 구현되어 있을 가능성 높음

#### 1.1. 문서 전달 및 설명회

**일정:** 클라이언트팀 준비 완료 시
**방법:** 문서 공유 + 간단한 설명 (30분)

**전달할 문서:**

1. `METRIC_API.md` (핵심)
2. `GROUP_API.md`
3. `ERROR(에러응답)API.md`

**설명 포인트:**

- ✅ **폴링 방식 중요성:** AI 요약은 비동기 작업이므로 2~3초 간격 폴링 필수
- ✅ **3가지 상태 처리:** PENDING(로딩), COMPLETED(완료), FAILED(실패)
- ✅ **에러 처리:** 200 OK + FAILED vs 500 Error 구분

#### 1.2. 연동 지원 (On-demand)

**대응 항목:**

- [ ] API 호출 방법 질문 답변
- [ ] 응답 데이터 파싱 이슈 해결
- [ ] 폴링 로직 구현 검토
- [ ] 에러 케이스 처리 가이드

**예상 질문:**

1. "폴링 주기는 몇 초가 적당한가요?" → 2~3초 권장
2. "PENDING 상태가 계속되면 어떻게 하나요?" → 최대 30초 대기 후 타임아웃 처리 권장
3. "에러 메시지를 어떻게 표시하나요?" → `data.reason` 필드 사용

#### 1.3. 테스트 데이터 확인

**작업:**

- [ ] H2 DB 초기 데이터 확인 (`PlanScenario01_Completed.java`)
- [ ] 완료된 약속이 있는지 확인
- [ ] AI 요약이 정상 생성되는지 확인

**필요시 추가 데이터 생성 가능**

### 이슈 2: 401 Unauthorized 에러

**원인:**

- JWT 토큰 누락 또는 만료

**대응:**

1. 헤더 형식 확인: `Authorization: Bearer {token}`
2. 토큰 유효성 확인
3. 로그인 재시도

### 이슈 3: WebSocket 연결 실패

**원인:**

- WebSocket URL 오류
- 인증 문제
- 방화벽/프록시 문제

**대응:**

1. URL 확인: `ws://localhost:8080/ws/...`
2. 인증 토큰 확인
3. 네트워크 설정 확인

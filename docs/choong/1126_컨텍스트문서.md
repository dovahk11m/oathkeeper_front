## 7. 개발 교훈 및 주의사항 (11/27 추가)

1. **State 필드 가변성 주의**

   - `StatefulWidget`의 `State` 클래스 내에서 `setState`로 값이 변경되는 필드(예: `_shareMyLocation`, `_myAlpha`)는 절대 `final`로 선언하지 않는다.
   - 컴파일러가 `setter not defined` 에러를 뱉을 때 가장 먼저 `final` 여부를 확인할 것.

2. **Deprecated API 대응**

   - Flutter 3.22+ 버전부터 `Color.withOpacity` 대신 `Color.withValues(alpha: ...)` 사용이 권장됨.
   - 서버 API 변경으로 `TrackingDto` 및 `fetchRecent`가 Deprecated됨. 최신 `TrackBatchRequest` 및 WebSocket 실시간 데이터로 대체해야 함.

3. **서버 스펙 동기화 필수**

   - 클라이언트 구현 전 반드시 최신 서버 API 문서(`LIVE_MAP_API.md` 등)를 확인해야 함.
   - 구 명세(예: `room` 토픽, `TrackingDto`)를 그대로 사용하면 서버와 통신 불가하거나 404/500 에러 발생.
   - 불확실한 경우 `docs/choong/` 폴더 내 QnA 문서를 통해 서버팀에 확인 요청.

4. **정적 분석 활용**
   - 코드 작성 후 `flutter analyze`를 실행하여 문법 오류(세미콜론 누락 등) 및 Deprecated 경고를 사전에 식별하고 수정하는 습관 필요.

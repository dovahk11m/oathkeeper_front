# 1126 환경 변수 정리 노트

## 왜 했나
- 코드 곳곳에 하드코딩된 IP/도메인(10.0.0.2, 192.168.0.3)이 있어 환경 바뀔 때마다 소스 수정이 필요함.
- 배포/스테이징/로컬을 번갈아 쓸 때 `.env`만 바꾸면 되도록 분리.
- 실수로 잘못된 IP를 코드에 남겨두는 리스크(대규모 리팩터링 필요)를 줄이기 위함.

## 무엇을 했나
- HTTP/이미지/Dio 기본 주소 → `.env`의 `API_BASE_URL`, `IMAGE_BASE_URL` 우선, 없으면 localhost로 fallback.
- AI 호출 → `.env`의 `AI_BASE_URL` 우선, 없으면 `http://192.168.0.3:8001/metrics`로 fallback.
- Endpoints 빌더 → `.env` 값 우선, 없으면 localhost/192.168.0.3 기본.
- 라이브맵 WS 기본값 → `.env` `WS_URL`(또는 후속 리팩터용 WS_LIVEMAP_URL) 없으면 localhost WS 사용.
- `.env.example`에 필요한 키와 기본값 정리.

## 어떻게 쓰나
- 로컬 기본값으로 그냥 돌릴 때: `.env` 없이도 localhost/192.168.0.3으로 동작.
- 환경 바꿀 때: `.env`에서 `API_BASE_URL`, `AI_BASE_URL`, `WS_CHAT_URL`/`WS_LIVEMAP_URL`만 원하는 주소로 교체.
- 소셜 키는 테스트 필요 시에만 채우고, git에는 포함하지 않음.

## 영향/주의
- 기능 변경 없음, 주소 주입 방식만 변경.
- 배포 시 `.env` 로딩이 선행되어야 함(flutters_dotenv 사용). 없습니다면 fallback으로 실행됨.
- AI 서버 주소가 필요 없는 경우 `AI_BASE_URL` 비워도 됨(필요 시만 채움).

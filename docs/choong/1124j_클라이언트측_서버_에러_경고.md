**작성일**: 2025-11-24 19:57
**심각도**: 🔴 긴급 (Critical)

---

## 요약

서버에서 **500 Internal Server Error**가 다수 발생하고 있으며, 여러 API가 정상 작동하지 않습니다.

---

## 발생 중인 에러

### 1. 🔴 약속 목록 조회 - 500 에러

**API**: `GET /api/groups/1/plans?status=COMPLETED&page=0&size=20&sort=planDatetime,DESC`

**상태**: 500 Internal Server Error

**응답**:

```json
{
  "success": false,
  "data": null,
  "message": "시스템 오류가 발생했습니다. 관리자에게 문의해주세요."
}
```

**이전 상태**: 정상 작동 (200 OK)
**현재 상태**: 서버 내부 오류

---

### 2. 🔴 채팅 메시지 조회 - 500 에러

**API**: 채팅 메시지 조회 (경로 미상)

**상태**: 500 Internal Server Error

**에러 메시지**:

```
[ChatRepo] 메시지 조회 실패: DioException [bad response]: status code of 500
[Chat] 메시지 로드 실패: 서버 연결에 실패했습니다.
```

---

### 3. ⚠️ 읽음 처리 - 404 에러 (API 미구현)

**API**: `POST /api/groups/1/chat/read`

**상태**: 404 Not Found

**에러**:

```
No static resource api/groups/1/chat/read
```

**원인**: API가 구현되지 않음

---

### 4. ⚠️ 활성 약속 조회 - 404 에러 (API 미구현)

**API**: `GET /api/plans/group/1/active`

**상태**: 404 Not Found

**에러**:

```
No static resource api/plans/group/1/active
```

**원인**: API가 구현되지 않음 (AI 서버 연동 필요)

# 1124f 약속 리스트 구현 계획

- **작성일:** 2025-11-24
- **목표:** 2탭 구조로 약속 상세보기/목록보기 기능 구현

---

## 📋 요구사항

### 배경

- GROUP_API.md에 새로운 API 추가: `GET /api/groups/{groupId}/plans?status=COMPLETED`
- 하나의 그룹에 여러 약속이 누적될 수 있음
- 사용자가 과거 약속 중 원하는 것을 선택하여 요약을 볼 수 있어야 함

### UI 구조

```
┌─────────────────────────────────────┐
│   약속 요약                          │
├─────────────────────────────────────┤
│  [상세보기]  [목록보기]              │ ← 탭
├─────────────────────────────────────┤
│                                     │
│  [상세보기 탭]                       │
│  - 선택된 약속의 AI 요약 표시        │
│  - 로딩/완료/실패 상태               │
│                                     │
│  [목록보기 탭]                       │
│  - 완료된 약속 목록 (COMPLETED)      │
│  - 각 항목: 제목, 날짜/시간          │
│  - 클릭 시 → 상세보기 탭으로 전환    │
│    + 해당 약속 요약 로딩 시작        │
│                                     │
└─────────────────────────────────────┘
```

### 동작 플로우

1. **시트 열림** → 기본적으로 "상세보기" 탭 (현재 planId의 요약 표시)
2. **"목록보기" 탭 클릭** → 완료된 약속 목록 표시
3. **목록에서 약속 클릭** → "상세보기" 탭으로 자동 전환 + 해당 약속 요약 로딩

#### 2.1. GroupRepository 수정

**파일:** `lib/domain/groups/group_repository.dart`

```dart
import 'package:dio/dio.dart';
import '../plans/simple_plan.dart';

class GroupRepository {
  final Dio _dio;

  GroupRepository(this._dio);

  // 기존 메서드들...

  /// 그룹 내 완료된 약속 목록 조회
  Future<PlanListResponse> fetchCompletedPlans(
    int groupId, {
    int page = 0,
    int size = 20,
  }) async {
    final resp = await _dio.get(
      '/groups/$groupId/plans',
      queryParameters: {
        'status': 'COMPLETED',
        'page': page,
        'size': size,
        'sort': 'planDatetime,DESC',
      },
    );

    // CommonResponse 구조 파싱
    final data = resp.data['data'];
    return PlanListResponse.fromJson(data);
  }
}
```

**작업:**

- `fetchCompletedPlans()` 메서드 추가

#### 3.2. 약속 목록 조회 메서드

```dart
Future<void> _loadPlanList() async {
  if (widget.groupId <= 0) return;

  setState(() => _loadingPlanList = true);

  try {
    final groupRepo = ref.read(groupRepositoryProvider);
    final response = await groupRepo.fetchCompletedPlans(widget.groupId);

    if (mounted) {
      setState(() {
        _planList = response.items;
        _loadingPlanList = false;
      });
    }
  } catch (e) {
    if (mounted) {
      setState(() => _loadingPlanList = false);
      _toast('약속 목록 조회 실패: $e');
    }
  }
}
```

#### 3.6. 목록보기 탭 UI

```dart
Widget _buildListTab() {
  if (_loadingPlanList) {
    return const Center(child: CircularProgressIndicator());
  }

  if (_planList.isEmpty) {
    return Center(
      child: Column(
        mainAxisAlignment: MainAxisAlignment.center,
        children: [
          Icon(Icons.event_busy, size: 64, color: Colors.grey),
          const SizedBox(height: 16),
          Text('완료된 약속이 없습니다.',
              style: theme.textTheme.titleMedium),
        ],
      ),
    );
  }

  return ListView.builder(
    padding: const EdgeInsets.all(16),
    itemCount: _planList.length,
    itemBuilder: (context, index) {
      final plan = _planList[index];
      final isSelected = plan.planId == _selectedPlanId;

      return Card(
        elevation: isSelected ? 4 : 1,
        color: isSelected
            ? theme.colorScheme.primaryContainer
            : null,
        child: ListTile(
          leading: Icon(
            Icons.event_available,
            color: isSelected
                ? theme.colorScheme.primary
                : null,
          ),
          title: Text(
            plan.title,
            style: TextStyle(
              fontWeight: isSelected
                  ? FontWeight.bold
                  : FontWeight.normal,
            ),
          ),
          subtitle: Text(_formatDateTime(plan.planDatetime)),
          trailing: isSelected
              ? Icon(Icons.check_circle,
                  color: theme.colorScheme.primary)
              : null,
          onTap: () => _onPlanSelected(plan.planId),
        ),
      );
    },
  );
}

String _formatDateTime(String datetime) {
  try {
    final dt = DateTime.parse(datetime);
    return '${dt.year}-${dt.month.toString().padLeft(2, '0')}-${dt.day.toString().padLeft(2, '0')} '
           '${dt.hour.toString().padLeft(2, '0')}:${dt.minute.toString().padLeft(2, '0')}';
  } catch (e) {
    return datetime;
  }
}
```

## 📎 부록: domain.metrics 구조 조정 계획

### 배경

약속 리스트 기능을 추가하면서 domain.metrics가 점점 복잡해지고 있습니다. `domain.members`처럼 세부 도메인으로 분리하고 배럴 파일로 정리하여 구조를 개선합니다.

### 현재 구조 (Before)

```
lib/domain/metrics/
├── metrics_provider.dart
├── metrics_repository.dart
├── metrics_state.dart
├── metrics_state.freezed.dart
├── plan_summary.dart
├── plan_summary.freezed.dart
├── plan_summary.g.dart
├── models/
│   ├── metrics_summary.dart
│   └── text_options.dart
└── repository/
    └── metrics_repository.dart (구 Python AI 서버용)
```

**문제점:**

- 파일들이 평면적으로 나열됨
- 기능별 그룹화가 안 됨
- import 경로가 복잡함

### 목표 구조 (After)

```
lib/domain/metrics/
├── metric.dart                    # 배럴 파일 (공개 API)
│
├── summary/                       # AI 요약 관련
│   ├── plan_summary.dart
│   ├── plan_summary.freezed.dart
│   ├── plan_summary.g.dart
│   ├── metrics_state.dart
│   ├── metrics_state.freezed.dart
│   ├── metrics_provider.dart
│   └── metrics_repository.dart
│
├── plan_list/                     # 약속 목록 (신규)
│   ├── simple_plan.dart
│   ├── simple_plan.freezed.dart
│   ├── simple_plan.g.dart
│   ├── plan_list_state.dart
│   └── plan_list_provider.dart
│
└── legacy/                        # 구 Python AI 직접 호출용 (deprecated)
    ├── metrics_summary.dart
    ├── text_options.dart
    └── metrics_repository.dart
```

### 배럴 파일 예시

**파일:** `lib/domain/metrics/metric.dart`

```dart
// [배럴 파일: Barrel File]
// metrics 도메인의 공개 API 역할
//
// [사용법]
// import 'package:oath_client/domain/metrics/metric.dart';

// ===================
// Summary: AI 요약 기능
// ===================
export 'summary/plan_summary.dart';
export 'summary/metrics_state.dart';
export 'summary/metrics_provider.dart' show metricsProvider;
export 'summary/metrics_repository.dart' show metricsRepositoryProvider;

// ===================
// Plan List: 약속 목록
// ===================
export 'plan_list/simple_plan.dart';
export 'plan_list/plan_list_state.dart';
export 'plan_list/plan_list_provider.dart' show planListProvider;
```

### Import 경로 개선

**Before:**

```dart
import '../../domain/metrics/metrics_provider.dart';
import '../../domain/metrics/metrics_state.dart';
import '../../domain/metrics/plan_summary.dart';
```

**After:**

```dart
import '../../domain/metrics/metric.dart';  // 배럴 파일 하나만!
```

### 주의사항

1. **Freezed 파일 재생성**

   - 파일 이동 후 `build_runner` 재실행 필수
   - `flutter pub run build_runner build --delete-conflicting-outputs`

2. **Git 이동 추적**

   - `git mv` 명령어 사용하여 파일 이동 이력 유지

3. **기존 코드 호환성**
   - `metrics_text_page.dart`는 아직 legacy 파일 사용 중
   - 점진적 마이그레이션 필요

2. ✅ 배럴 파일로 import 단순화
3. ✅ 향후 확장 용이 (statistics 등 추가 가능)

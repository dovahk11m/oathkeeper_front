### 3. 필드명 불일치 비교표

| 기능               | API 문서        | 실제 서버 응답  | 상태                  |
| ------------------ | --------------- | --------------- | --------------------- |
| 약속 리스트        | `items`         | `content`       | ❌ 불일치             |
| 현재 페이지        | `currentPage`   | `page`          | ❌ 불일치             |
| 전체 페이지 수     | `totalPages`    | `totalPage`     | ❌ 불일치 (단수/복수) |
| 전체 요소 수       | `totalElements` | `totalElements` | ✅ 일치               |
| 첫 페이지 여부     | `isFirst`       | (없음)          | ❌ 누락               |
| 마지막 페이지 여부 | `isLast`        | `last`          | ❌ 불일치             |
| 네비게이션 정보    | (없음)          | `navigation`    | ℹ️ 추가 필드          |

### 4. 클라이언트 오류 로그

```
[PlanListNotifier] 약속 목록 조회 실패: type 'Null' is not a subtype of type 'List<dynamic>' in type cast
```

클라이언트는 문서 명세에 따라 `items` 필드를 파싱하려 하지만, 실제 응답에는 `content` 필드만 존재하여 null 참조 오류가 발생합니다.

## 원인 분석

현재 서버 응답 구조는 **Spring Data JPA의 기본 `Page` 인터페이스 구조**를 그대로 사용하고 있는 것으로 보입니다:

```java
// Spring의 기본 Page 구조
{
  "content": [...],      // Page.getContent()
  "pageable": {...},
  "totalPages": ...,
  "totalElements": ...,
  "last": ...,           // Page.isLast()
  "first": ...,          // Page.isFirst()
  // ...
}
```

하지만 API 문서에는 커스텀 `PageResponseDTO` 구조가 명시되어 있습니다.

---

## 해결 방안

### 옵션 1: 서버 수정 (권장)

`PageResponseDTO` 클래스를 문서 명세에 맞게 구현하거나 수정합니다.

**예상 코드**:

```java
public class PageResponseDTO<T> {
    private List<T> items;           // content -> items
    private int currentPage;         // page -> currentPage
    private int totalPages;          // totalPage -> totalPages
    private long totalElements;
    private boolean isFirst;         // 추가 필요
    private boolean isLast;          // last -> isLast

    // Spring Page를 받아서 변환하는 생성자
    public PageResponseDTO(Page<T> page) {
        this.items = page.getContent();
        this.currentPage = page.getNumber();
        this.totalPages = page.getTotalPages();
        this.totalElements = page.getTotalElements();
        this.isFirst = page.isFirst();
        this.isLast = page.isLast();
    }
}
```

### 옵션 2: 문서 수정

API 문서를 실제 서버 응답 구조에 맞게 수정합니다. (권장하지 않음 - 다른 API와의 일관성 문제)

### 옵션 3: 클라이언트 임시 대응

클라이언트에서 `@JsonKey` 어노테이션으로 필드 매핑을 추가합니다. (임시 방편)

## 영향 범위

이 문제는 `PageResponseDTO`를 사용하는 **모든 API**에 영향을 미칠 수 있습니다:

- ✅ `GET /api/groups` - 그룹 목록 조회 (동일한 문제 확인됨)
- ✅ `GET /api/groups/{groupId}/plans` - 약속 목록 조회 (현재 이슈)
- ⚠️ `GET /api/groups/{groupId}/members` - 멤버 목록 조회 (미확인)
- ⚠️ `GET /api/groups/{groupId}/chat/messages` - 채팅 메시지 조회 (미확인)

**권장**: `PageResponseDTO`를 전체적으로 점검하고 일관되게 수정해주시기 바랍니다.

# 📌 Oathkeeper Python Metrics/LLM 서비스 – 요약 API 명세 (전달용)

### 📍 Python FastAPI Base URL

```
http://<PYTHON_HOST>:8001
```

---

## 🔁 1) 이동 기록 저장 (Spring → Python)

**POST /metrics/analyze**

* 약속 종료 후 계산된 메트릭(거리/시간/지각/대기)을 Python 서비스로 전달
* Python은 `plan_x/metrics.jsonl`에 누적 저장 + 점수 계산 후 응답

### 📤 Request Body (MetricsPayload)

```json
{
  "plan_id": 2,
  "member_id": 1,
  "distance_km": 3.2,
  "travel_minutes": 18,
  "late_minutes": 2,
  "wait_minutes": 0
}
```

### 📥 Response 예시

```json
{
  "success": true,
  "data": {
    "plan_id": 2,
    "member_id": 1,
    "score": 98.0,
    "summary": "3.20km 이동, 18분 소요"
  }
}
```

---

## 📊 2) 요약 보고서 생성 + 저장

**GET /metrics/report/{planId}**

* summary.json 생성 및 저장 (`data/plan_x/summary.json`)
* summary_history에도 시점별 백업

### 📥 Response 예시

```json
{
  "summary": { ... },
  "saved": {
    "summary_path": ".../summary.json",
    "history_path": ".../summary_history/2025xxxx.json"
  }
}
```

---

## 🗣️ 3) 기본 텍스트 요약 (규칙 기반)

**GET /metrics/report/{planId}/text**

* LLM 없이 규칙 기반으로 한 줄 텍스트 전달

### 📥 Response 예시

```
철수는 약속 장소까지 3.2km 이동했고 18분이 걸렸습니다. 이번 약속에서는 전체적으로 이동 거리가 길었습니다...
```

---

## 🤖 4) LLM 기반 텍스트 요약 (Flutter/Spring 전용)

**POST /metrics/report/{planId}/text**

* `mode`, `style`, `notes`, `name_map` 옵션 전달 가능
* Ollama (기본 모델: llama3.1) 호출 → 자연어 출력

### 📤 Request Body

```json
{
  "mode": "llm",
  "style": "친근하고 조언하는 말투",
  "notes": "지각 많은 멤버는 부드럽게 충고",
  "name_map": {
    "1": "철수",
    "2": "영희"
  }
}
```

### 📥 Response 예시

```json
{
  "success": true,
  "data": "철수는 약속 장소까지 비교적 먼 거리를 이동했고, 영희는 대기 시간이 조금 있었습니다. 다음 약속에서는 출발 시간을 조금만 더 여유있게 하면 좋겠어요!"
}
```

## 🚨 에러 규칙 (중요)

| Code | 상황         | 클라이언트 처리         |
| ---- | ---------- | ---------------- |
| 404  | plan 폴더 없음 | 현재 활성 약속 없음      |
| 409  | 기록 0개      | 아직 집계할 이동 데이터 부족 |

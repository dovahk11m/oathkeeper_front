## 📋 요구사항

### 현재 문제점

현재 `metrics_summary_sheet.dart`의 탭 구조:

- **좌측 탭 (상세보기)**: 개별 약속의 AI 요약 표시
- **우측 탭 (목록보기)**: 그룹 내 완료된 약속 목록

### 원하는 기능

```
┌─────────────────────────────────────┐
│   약속 요약                          │
├─────────────────────────────────────┤
│  [그룹 통계]  [약속 목록]            │ ← 탭
├─────────────────────────────────────┤
│                                     │
│  [그룹 통계 탭] ← 좌측               │
│  - 그룹 전체 누적 통계 표시          │
│  - AI 자연어 요약 (text_summary)    │
│  - GET /api/groups/{groupId}/       │
│    metrics/summary                  │
│                                     │
│  [약속 목록 탭] ← 우측               │
│  - 완료된 약속 목록 (COMPLETED)      │
│  - 약속 클릭 시 → 개별 약속 요약     │
│    바텀시트/다이얼로그로 표시        │
│                                     │
└─────────────────────────────────────┘
```

### 동작 플로우

1. **시트 열림** → "그룹 통계" 탭이 기본 (그룹 전체 누적 통계 표시)
2. **"약속 목록" 탭 클릭** → 완료된 약속 목록 표시
3. **목록에서 약속 클릭** → 새로운 바텀시트/다이얼로그로 개별 약속 요약 표시

## 📝 API 스펙

### 그룹 누적 통계 조회

**Endpoint**: `GET /api/groups/{groupId}/metrics/summary`

**Response (성공)**:

```json
{
  "success": true,
  "data": {
    "group_summary": {
      "total_plans_analyzed": 4,
      "total_records": 128,
      "total_distance_km": 258.4,
      "avg_distance_per_plan_km": 64.6,
      "total_late_minutes": 45,
      "avg_late_minutes_per_plan": 11.25
    },
    "text_summary": "분석된 4개의 약속에 따르면..."
  },
  "message": "그룹 통계 조회가 완료되었습니다."
}
```

**Response (약속 없음)**:

```json
{
  "success": true,
  "data": {
    "message": "통계를 생성할 약속이 없습니다.",
    "group_summary": {}
  },
  "message": "그룹 통계 조회가 완료되었습니다."
}
```

# 실시간 지도 리팩토링 작업 기록

**날짜**: 2025-11-27
**작업자**: AI Assistant
**관련 문서**: `LIVE_MAP_API.md`, `1127c_실시간지도_QNA.md`

---

## 🎯 작업 목표

구 명세(`room` 토픽)를 사용하는 클라이언트 코드를 최신 `LIVE_MAP_API` 스펙(`plans` 토픽)으로 업데이트하고, 누락된 이벤트 처리 로직을 구현하여 서버와의 호환성을 확보합니다.

---

## 🛠️ 주요 변경 사항

### 1. WebSocket 토픽 마이그레이션

**Before (구 명세)**:

- 위치 브로드캐스트: `/topic/room/{planId}`
- Presence 브로드캐스트: `/topic/room/{planId}/presence`
- Presence 전송: `/app/room/{planId}/presence`

**After (최신 스펙)**:

- 실시간 위치 업데이트: `/topic/plans/{planId}/live`
- 이벤트 알림: `/topic/plans/{planId}/events`

**구현 내용**:

- `LiveMapPage`의 `_connectStomp` 메서드에서 구독 토픽 변경.
- 클라이언트 주도의 Presence 전송 로직(`_sendPresence`) 제거 (서버가 위치 업데이트를 기반으로 자동 관리).

### 2. DTO 구조 개선

**Before**:

- `TrackingDto` 사용 (필드 부족, 서버 응답과 불일치 가능성)

**After**:

- `LiveLocationDto` 신규 생성 (`lib/domain/tracking/live_location_dto.dart`)
- 서버 응답(`memberId`, `username`, `profileImageUrl`, `lat`, `lng`, `lastLiveTs`)과 1:1 매핑되는 `freezed` 클래스 적용.

### 3. 이벤트 처리 로직 구현

**추가된 기능**:

- **GPS 정체 알림 (`GPS_STATIONARY`)**: 사용자가 한 장소에 오래 머물 때 서버가 보내는 알림을 수신하여 `SnackBar`(주황색)로 표시.
- **참가자 도착 알림 (`PARTICIPANT_ARRIVED`)**: 참가자가 약속 장소에 도착했을 때 서버가 보내는 알림을 수신하여 `SnackBar`(초록색)로 표시.

**구현 코드**:

```dart
void _handleEvent(Map<String, dynamic> event) {
  // ...
  if (eventType == 'PARTICIPANT_ARRIVED') {
    snackColor = Colors.green;
  } else if (eventType == 'GPS_STATIONARY') {
    snackColor = Colors.orange;
  }
  // SnackBar 표시
}
```

### 4. 코드 정리 및 최적화

- **Deprecated API 제거**: `TrackingRepository.fetchRecent` 호출 로직(`_loadRecentAll`) 제거. 초기 데이터는 WebSocket 연결 후 수신되는 실시간 데이터로 채워짐.
- **불필요한 Timer 제거**: Presence 전송용 타이머 제거.
- **컴파일 에러 수정**: 리팩토링 과정에서 발생한 문법 오류 수정 및 빌드 완료.

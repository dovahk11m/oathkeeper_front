# 약속 요약 기능 Q&A

## Q. 완료된 약속이 목록에서 '미완료'로 표시되고 클릭이 안 됩니다.

**A.**

1. **현상**

   - DB 데이터 확인 결과, 해당 약속의 상태는 `COMPLETED`로 정상 저장되어 있습니다.
   - 하지만 앱(클라이언트)에서는 해당 약속을 '완료되지 않은 약속'으로 표시하고, 클릭 이벤트를 막고 있습니다.

2. **원인 분석**

   - 클라이언트는 `SimplePlan` 모델의 `status` 필드를 확인하여 완료 여부(`isCompleted`)를 판단합니다.
   - 현재 `GROUP_API.md` 문서의 `2.4. 그룹 내 약속 목록 조회` API 응답 예시를 보면 `status` 필드가 포함되어 있지 않습니다.
   - **결론**: 서버 API가 응답 데이터에 `status` 필드를 내려주지 않아, 클라이언트가 이를 `null`로 인식하고 있는 것으로 보입니다.

3. **조치 요청**
   - **서버팀**: `GET /api/groups/{groupId}/plans` API의 응답 DTO에 `status` 필드를 추가해주세요.
   - **클라이언트**: 서버 수정 후 별도 조치 없이 정상 동작할 것으로 예상됩니다. (이미 대소문자 무시 로직 `isCompleted` 적용 완료)

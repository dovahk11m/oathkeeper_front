## 📋 현황 분석

### 서버 API 변경사항

#### 1. Spring 서버 API (METRIC_API.md)

- **엔드포인트:** `GET /api/plans/{planId}/summary`
- **폴링 방식:** 클라이언트가 2~3초 간격으로 주기적 호출
- **응답 상태:**
  - `data: null` + message → 생성 중 (계속 폴링)
  - `data: { id, title, summary }` → 완료 (폴링 중단)
  - `500 에러` → 실패 (폴링 중단)

#### 2. Python AI 서버 API (1124aAI서버명세.md)

- **메트릭 저장:** `POST /metrics/analyze` (Spring → Python)
- **요약 생성:** `GET /metrics/report/{planId}`
- **규칙 기반 요약:** `GET /metrics/report/{planId}/text`
- **LLM 요약:** `POST /metrics/report/{planId}/text`
- **에러 코드:**
  - `404` → plan 폴더 없음
  - `409` → 메트릭 데이터 부족

```dart
/// Spring API 응답 DTO
@freezed
class PlanSummaryData with _$PlanSummaryData {
  const factory PlanSummaryData({
    required int id,
    required String title,
    required String summary,
  }) = _PlanSummaryData;

  factory PlanSummaryData.fromJson(Map<String, dynamic> json) =>
      _$PlanSummaryDataFromJson(json);
}

@freezed
class PlanSummaryResponse with _$PlanSummaryResponse {
  const PlanSummaryResponse._();

  const factory PlanSummaryResponse({
    required bool success,
    PlanSummaryData? data,
    String? message,
  }) = _PlanSummaryResponse;

  factory PlanSummaryResponse.fromJson(Map<String, dynamic> json) =>
      _$PlanSummaryResponseFromJson(json);

  /// 생성 중 상태 확인
  bool get isProcessing => success && data == null && message != null;

  /// 완료 상태 확인
  bool get isCompleted => success && data != null;
}
```

**특징:**

- Spring API 응답 구조에 맞춘 DTO
- `isProcessing`, `isCompleted` 헬퍼 메서드 제공
- freezed + json_serializable 사용

#### 1.4. Provider 파일 생성

**파일:** `lib/domain/metrics/metrics_provider.dart`

```dart
class MetricsNotifier extends Notifier<MetricsState> {
  Timer? _pollingTimer;

  @override
  MetricsState build() {
    ref.onDispose(() {
      cancelSummaryPolling();
    });
    return const MetricsState();
  }

  /// AI 요약 폴링 시작 (3초 간격)
  Future<void> pollPlanSummary(int planId) async {
    // 기존 폴링 취소
    cancelSummaryPolling();

    // 로딩 상태로 전환
    state = state.copyWith(
      isSummaryLoading: true,
      summaryStatus: SummaryStatus.processing,
      error: null,
    );

    // 첫 번째 요청 즉시 실행
    await _fetchSummary(planId);

    // 폴링 시작 (3초 간격)
    _pollingTimer = Timer.periodic(const Duration(seconds: 3), (_) async {
      await _fetchSummary(planId);
    });
  }

  /// 폴링 중단
  void cancelSummaryPolling() {
    _pollingTimer?.cancel();
    _pollingTimer = null;
  }
}

final metricsProvider =
    NotifierProvider<MetricsNotifier, MetricsState>(MetricsNotifier.new);
```

**핵심 기능:**

1. **폴링 로직**

   - 3초 간격으로 Spring API 호출
   - 첫 요청은 즉시 실행
   - 완료/실패 시 자동 중단

2. **에러 처리**

   - `404` → "활성화된 약속이 없습니다."
   - `409` → "아직 메트릭 데이터가 집계되지 않았습니다."
   - `500` → "AI 요약 생성에 실패했습니다."

3. **메모리 관리**
   - `ref.onDispose()`로 자동 정리
   - `cancelSummaryPolling()`로 Timer 해제

```dart
@override
void initState() {
  super.initState();
  WidgetsBinding.instance.addPostFrameCallback((_) async {
    if (!mounted) return;

    // 멤버 이름 조회
    final Dio app = ref.read(dioProvider);
    _membersRepo = MembersRepository(app);
    try {
      _nameMap = await _membersRepo?.fetchNameMapByPlan(widget.planId);
      if (mounted) setState(() {});
    } catch (_) {}

    if (!mounted) return;

    // 폴링 시작
    if (widget.planId > 0) {
      ref.read(metricsProvider.notifier).pollPlanSummary(widget.planId);
    }
  });
}
```

```dart
@override
Widget build(BuildContext context) {
  final theme = Theme.of(context);
  final metricsState = ref.watch(metricsProvider);

  // 상태별 UI 분기
  Widget content;
  if (widget.planId <= 0) {
    content = _buildNoPlanView(context);
  } else if (metricsState.summaryStatus == SummaryStatus.failed) {
    // 에러 코드별 분기
    if (metricsState.error?.contains('활성화된 약속') ?? false) {
      content = _buildNoPlanView(context);
    } else if (metricsState.error?.contains('집계되지') ?? false) {
      content = _buildNotReadyView(context);
    } else {
      content = _buildErrorCard(theme, metricsState.error ?? '알 수 없는 오류');
    }
  } else if (metricsState.summaryStatus == SummaryStatus.completed) {
    content = _buildSummaryCard(theme, metricsState.summaryText ?? '');
  } else {
    // processing or idle - 로딩 표시
    content = _buildSummaryCard(theme, '');
  }

  final isLoading = metricsState.isSummaryLoading;

  return ClipRRect(
    borderRadius: const BorderRadius.vertical(top: Radius.circular(24)),
    child: Material(
      color: theme.colorScheme.surface,
      child: Stack(
        children: [
          SafeArea(
            top: false,
            child: Padding(
              padding: const EdgeInsets.fromLTRB(16, 12, 16, 24),
              child: Column(
                mainAxisSize: MainAxisSize.min,
                children: [
                  // 핸들, 제목, 멤버 목록...

                  // 내용
                  AnimatedSwitcher(
                    duration: const Duration(milliseconds: 250),
                    child: content,
                  ),

                  const SizedBox(height: 16),

                  // 하단 버튼
                  FilledButton.icon(
                    onPressed: isLoading
                        ? null
                        : () => ref.read(metricsProvider.notifier)

                    icon: const Icon(Icons.refresh),
                    label: const Text('다시 불러오기'),
                  ),
                ],
              ),
            ),
          ),
          if (isLoading) _buildLoadingOverlay(context),
        ],
      ),
    ),
  );
}
```

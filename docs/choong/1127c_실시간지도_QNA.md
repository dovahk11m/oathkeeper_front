**질문**: 다음 토픽들이 현재 서버에서 지원되나요?

#### 1. WebSocket 토픽 지원 여부

**✅ 최신 스펙 (LIVE_MAP_API.md) - 정상 작동**

| 토픽                           | 상태        | 구현 위치                                                               |
| ------------------------------ | ----------- | ----------------------------------------------------------------------- |
| `/topic/plans/{planId}/live`   | ✅ **지원** | `LocationUpdateListener.java:22`                                        |
| `/topic/plans/{planId}/events` | ✅ **지원** | `GpsStationaryListener.java:63`<br>`ParticipantArrivedListener.java:44` |

**확인 코드:**

```java
// LocationUpdateListener.java
String destination = "/topic/plans/" + event.getPlanId() + "/live";
messaging.convertAndSend(destination, liveLocationDto);

// GpsStationaryListener.java & ParticipantArrivedListener.java
String websocketDestination = "/topic/plans/" + event.getPlanId() + "/events";
messaging.convertAndSend(websocketDestination, notificationDto);
```

**⚠️ 구 스펙 - Deprecated (사용 비권장)**

| 토픽                            | 상태              | 비고                                           |
| ------------------------------- | ----------------- | ---------------------------------------------- |
| `/topic/room/{planId}`          | ⚠️ **Deprecated** | `LocationService.java`에 잔존하지만 사용 안 함 |
| `/topic/room/{planId}/presence` | ❌ **미지원**     | 제거됨                                         |

**권장사항**: 구 스펙 토픽은 사용하지 마세요. 최신 스펙으로 마이그레이션 필요합니다.

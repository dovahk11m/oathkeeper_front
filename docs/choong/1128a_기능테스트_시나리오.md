# 1128 기능 테스트 시나리오

**목표**: 로컬 서버 연동하여 실시간 지도 및 AI 요약/메트릭스 기능 검증
**예상 소요 시간**: 4시간
**테스트 환경**: 로컬 서버 실행 중, Android 에뮬레이터/실기기

---

## Phase 1: 실시간 지도 서버 연동 테스트 (1.5시간)

### 1-1. 기본 연결 테스트 (30분)

- [ ] Flutter 앱 실행 (Android 에뮬레이터 or 실기기)
- [ ] 로그인 → 그룹 선택 → 약속 생성
- [ ] 실시간 지도 진입
- [ ] WebSocket 연결 확인 (로그 체크)
- [ ] `/topic/plans/{planId}/live` 구독 확인
- [ ] `/topic/plans/{planId}/events` 구독 확인

### 1-2. 위치 공유 기능 테스트 (30분)

- [ ] "내 위치 공유" 스위치 ON
- [ ] 위치 권한 허용 확인
- [ ] 내 마커가 지도에 표시되는지 확인
- [ ] 5초마다 위치 업로드 확인 (로그 체크)
- [ ] 서버 로그에서 `POST /api/track/tracks/bulk` 수신 확인

### 1-3. 다중 사용자 테스트 (30분)

- [ ] 2대 디바이스 or 에뮬레이터 + 실기기 조합
- [ ] 양쪽에서 동일 약속의 실시간 지도 진입
- [ ] 상대방 마커가 실시간으로 표시되는지 확인
- [ ] 접속자 수 표시 확인
- [ ] 한쪽에서 위치 공유 OFF 시 마커 사라지는지 확인

---

## Phase 2: 이벤트 처리 테스트 (1시간)

### 2-1. GPS 정체 이벤트 (30분)

- [ ] 서버 테스트 API 사용: `POST /api/test/force-stationary`
- [ ] `GPS_STATIONARY` 이벤트 수신 확인
- [ ] SnackBar에 주황색 알림 표시 확인
- [ ] 메시지 내용 확인

### 2-2. 도착 이벤트 (30분)

- [ ] 서버 테스트 API 사용: `POST /api/test/force-arrived`
- [ ] `PARTICIPANT_ARRIVED` 이벤트 수신 확인
- [ ] SnackBar에 녹색 알림 표시 확인
- [ ] 메시지 내용 확인 (사용자 이름 포함 여부)

---

## Phase 3: AI 요약/메트릭스 통합 테스트 (1시간)

### 3-1. 그룹 메트릭스 요약 테스트 (30분)

- [ ] 약속 완료 후 메트릭스 화면 진입
- [ ] 그룹 통계 탭 확인
- [ ] 폴링 로직 동작 확인 (2초 간격, race condition 없는지)
- [ ] PENDING → COMPLETED 상태 전환 확인
- [ ] AI 요약 텍스트 표시 확인

### 3-2. 개별 약속 요약 테스트 (30분)

- [ ] 약속 목록 탭에서 완료된 약속 선택
- [ ] 개별 요약 시트 표시 확인
- [ ] 폴링 로직 동작 확인 (3초 간격)
- [ ] 요약 텍스트 표시 확인
- [ ] 여러 약속 전환 시 정상 동작 확인

---

## Phase 4: 에러 케이스 및 안정성 테스트 (30분)

### 4-1. 네트워크 에러 처리

- [ ] 비행기 모드 ON → WebSocket 끊김 확인
- [ ] 비행기 모드 OFF → 재연결 확인
- [ ] 위치 업로드 실패 시 에러 처리 확인

### 4-2. 권한 에러 처리

- [ ] 위치 권한 거부 시 토스트 메시지 확인
- [ ] 위치 서비스 OFF 시 설정 화면 이동 확인

---

## Phase 5: 서버 이슈 확인 및 정리 (30분)

### 5-1. 약속 목록 status 필드 확인

- [ ] `GET /api/groups/{groupId}/plans` 호출
- [ ] 응답에 `status` 필드 포함 여부 확인
- [ ] 완료된 약속이 제대로 표시되는지 확인

### 5-2. 테스트 결과 문서화

- [ ] 발견된 버그/이슈 기록
- [ ] 정상 동작 항목 체크
- [ ] 개선 필요 사항 정리
- [ ] 테스트 결과를 이 문서에 업데이트

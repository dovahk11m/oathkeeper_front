## 2. 채팅 리스트 초기 로딩 문제 해결 (18:11)

### 문제 상황

- 앱 접속 시 채팅 리스트가 정상적으로 표시되지 않음
- 새 채팅을 만들면 갑자기 모든 채팅 리스트가 표시됨

### 원인

`groupsProvider`가 `FutureProvider`로 구현되어 있어, 초기 로딩 시 데이터가 제대로 트리거되지 않음

### 해결 방법

1. **초기 로딩 강제 트리거**: `initState`에서 `ref.read(groupsProvider)` 호출
2. **새로고침 버튼 추가**: AppBar에 새로고침 아이콘 버튼 추가

### 수정 파일

- `lib/view/chat/chat_list_screen.dart`
  - `initState`에서 초기 데이터 로드 명시적 호출
  - AppBar에 새로고침 버튼 추가 (refresh 아이콘)
  - 각 버튼에 tooltip 추가로 접근성 개선

### 테스트 필요

- [ ] 앱 재시작 시 채팅 리스트 정상 표시 확인
- [ ] 새로고침 버튼 동작 확인
